# Student Management App — Screen Design

## 1. Login Screen
- App logo and title
- Email field
- Password field
- Login button
- Link to registration

## 2. Registration Screen
- Full name
- Email
- Password
- Confirm password
- Register button

## 3. Dashboard Screen
- Welcome message
- Total courses card
- Attendance percentage card
- Pending assignments card
- Upcoming assignments list
- Weather information

## 4. Courses Screen
- List of enrolled courses
- Course code and title
- Add course button
- Edit and delete actions

## 5. Attendance Screen
- Select course
- Mark present or absent
- View attendance history
- Attendance percentage

## 6. Assignments Screen
- Assignment title
- Course name
- Due date
- Pending or completed status
- Add, edit and delete actions

## 7. Profile Screen
- Student name
- Email
- Edit profile
- Logout

## Navigation
Bottom navigation:
Home | Courses | Attendance | Assignments | Profile

## Design Guidelines
- Blue and white colour theme
- Consistent spacing
- Readable typography
- Clear buttons and form labels
- Responsive layouts
- Accessible colour contrast
